# Portfolio — Bhavesh Khatri

Personal portfolio of Bhavesh Khatri — Full-Stack Developer & AI/ML Student at JIET Jodhpur.

## 🔗 Live Demo

**[https://bhavesh-portfolio-pink-five.vercel.app](https://bhavesh-portfolio-pink-five.vercel.app)**

## 📸 Sections

- **Hero** — Introduction, role, and quick contact links
- **About** — Brief background and focus areas
- **Experience** — Internship at IIT Kharagpur (NPTEL) and B.Tech details
- **Projects** — Accord Living, Traceback, Eduverse
- **Skills** — Languages, frameworks, tools, and concepts
- **Contact** — Email and location info

## 🛠 Tech Stack

- **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Deployed on Vercel**

## 🚀 Run Locally

```bash
git clone https://github.com/Khatribhavesh05/bhavesh-portfolio.git
cd bhavesh-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
